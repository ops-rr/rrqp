外部圖片／影片連結測試

確認測驗頁面能不能直接顯示 DMS 的圖片或影片連結，以及連結隔多久會失效。

1. 貼上要測的連結

在新分頁開啟

網址帶有簽章，等同這張圖的通行證。請只貼在這個測試框，不要把網址寫進任何會上傳 GitHub 的檔案。測試紀錄只存在你這台瀏覽器（localStorage）。

2. 測試結果

3. 怎麼解讀

  • 圖片測試成功：測驗頁面可以直接嵌入縮圖。
  • 圖片測試失敗，但「在新分頁開啟」看得到：多半是瀏覽器擋第三方 cookie 或需要登入。測驗頁面改成縮圖位置放按鈕，點開新分頁看。
  • 「跨站讀取內容」失敗不影響顯示，只代表網頁程式不能讀取圖片的位元組，我們不需要這個。
  • 「不帶來源網址」成功、「預設」失敗：對方依來源網站判斷，測驗頁面可以設定不送來源網址。

要測的情境（每種都跑一次）：

  • 你的電腦，已登入 DMS，在內網。
  • 同一台電腦用無痕視窗，沒登入 DMS。
  • 不在內網（手機行動網路，或請菲律賓同事代測）。
  • 隔幾天、一週、一個月後，用「測試紀錄」重測同一個網址，確認有沒有過期。
